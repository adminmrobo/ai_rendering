일상으로 치면

블록을 종류별로 나누려고 자를 들었다. 보이는 가로·세로를 재면 같은 막대도 누우면 "가로가 긴 블록", 서면 "세로가 긴 블록"이 된다. 긴 변·짧은 변을 재면 방향은 해결되지만, 회사마다 칸 크기가 달라 큰 T자와 작은 막대가 헷갈린다. 게다가 T자와 L자는 둘 다 3×2칸이라 길이로는 구별이 안 된다. 둘을 가르는 건 갈래 수다. T자는 가운데 칸이 세 방향으로 갈라진다.

모델에서는

k-평균은 특징 숫자들의 차이(거리)로 "가깝다"를 정한다. 그래서 숫자 폭이 큰 특징이 결과를 좌우한다. 긴 변(18~60mm) 옆에 갈래 수(2~3개)를 그냥 놓으면 갈래 수는 묻힌다. 특징마다 평균을 빼고 표준편차로 나누는 표준화를 하면, 모든 특징이 같은 눈금을 갖는다.

먼저 시험 점수로 — 세 과목 중 어느 과목을 가장 잘 봤나?

수학 80점, 영어 85점, 국어 75점. 그런데 반 평균도 다르고, 반 친구들 점수가 퍼진 정도(표준편차)도 다르다. 표준편차는 "보통 친구들이 평균에서 이 정도는 떨어져 있다"는 폭이다. 이 폭을 자의 한 눈금으로 쓰면 세 과목을 한 줄에 세울 수 있다.

초보자를 위한 풀이 — 재는 법이 결과를 정하는 이유

  1. 거리 = 숫자 차이. 두 블록의 특징 차이를 합쳐 "얼마나 다른가"를 잰다. 직선 거리는 피타고라스, 바둑판 거리는 차이를 그냥 더한다.
  2. 보이는 그대로는 방향에 속는다(65.0%). 같은 막대가 누우면 가로 48·세로 12, 서면 가로 12·세로 48이다. 컴퓨터에게는 전혀 다른 두 블록이다. 긴 변·짧은 변으로 바꾸면 방향 문제가 풀린다(71.3%). 3부작의 최종 미션 "어느 각도에서든 조수 알아보기"의 아주 작은 예고편이다.
  3. 큰 숫자가 이긴다(71.3% 그대로). T자를 가르는 갈래 수를 더해도 결과가 같다. 긴 변의 숫자 폭은 40mm가 넘는데 갈래 수는 폭이 1개뿐이라 묻힌다.
  4. 표준화로 눈금을 맞춘다(84.3%). 시험 점수와 같다. 갈래 1개 차이는 표준편차 약 2.2개, 긴 변 1mm 차이는 약 0.1개다. 숫자의 크기가 아니라 "보통 흔들리는 폭에 비해 얼마나"를 보니 T자가 깔끔히 모였다.
  5. 그래도 크기에 속는다 → 크기에 안 속는 특징을 만든다(100%). 표준화한 뒤에도 네모와 L자가 "작은 것끼리, 큰 것끼리" 섞였다. 긴 변 ÷ 짧은 변(모양 비율)은 블록이 크든 작든 같은 값이다. 표준화는 눈금을 맞출 뿐, 무엇을 잴지는 사람이 정한다.

아래 "T자 블록 하나를 바꿔 보기"가 이 차이를 보여 준다. mm 그대로 재는 자는 칸 크기라는 흔한 차이에 크게 흔들리고, 갈래 수라는 중요한 차이는 못 듣는다. 결과가 이상하게 출렁이면 먼저 자부터 의심한다.

수식으로 보기 — 거리, 표준화, 민감도

직선(유클리드) 거리: d(a, b) = √(Σⱼ (aⱼ − bⱼ)²). 바둑판(맨해튼) 거리: d(a, b) = Σⱼ |aⱼ − bⱼ|.

표준화: 특징 j마다 z = (x − 평균ⱼ) / 표준편차ⱼ. 그러면 모든 특징의 평균은 0, 표준편차는 1이 된다.

민감도: 특징 j가 Δ만큼 바뀌면 표준화한 공간에서는 Δ / 표준편차ⱼ만큼 움직인다. 이 블록들의 표준편차는 긴 변 10.4mm, 짧은 변 6.1mm, 갈래 수 0.46개다. 그래서 갈래 1개 차이(2.2)가 긴 변 1mm 차이(0.1)보다 약 23배 멀리 움직인다. 주머니가 바뀌는 곳은 두 주머니 중심의 한가운데다.

2주머니 수

주머니는 몇 개? — 엘보 방법과 실루엣

모델: 묶음 안 거리 제곱합이 크게 줄다가 덜 줄기 시작하는 곳일상: 주머니를 하나씩 늘려 보기

일상으로 치면

주머니를 하나씩 늘려 본다. 1개 → 2개로 늘리면 정리가 확 깔끔해진다. 3개도 꽤 좋아진다. 그런데 어느 순간부터는 좋아지는 정도가 미미하다. "확 좋아지다가 더는 별로인" 지점이 알맞은 주머니 수다. 팔꿈치(엘보)처럼 꺾이는 곳이다.

모델에서는

주머니 수 k마다 k-평균을 돌리고, 묶음 안 블록들이 중심에서 얼마나 떨어졌는지(거리 제곱합)를 잰다. k를 늘리면 이 값은 늘 줄어든다. 그래서 가장 작은 값이 아니라 꺾이는 곳을 고른다(엘보 방법)[3]. 묶음끼리 얼마나 떨어졌는지 보는 실루엣 점수도 함께 본다[4]. 특징은 ①칸의 ⑤(모양 비율·갈래 수)를 쓴다.

행동으로 보기 — 주머니마다 든 블록

초보자를 위한 풀이 — 점수가 늘 좋아지는 함정

  1. 주머니를 늘리면 각 블록이 더 가까운 중심을 갖게 되니, 거리 제곱합은 무조건 줄어든다. 주머니를 블록 수만큼(300개) 만들면 0이 된다. 그건 정리가 아니다.
  2. 그래서 "얼마나 줄었나"를 본다. 600 → 258 → 6.3 → 1.8로, 줄어든 양은 342, 252, 4.5다. 3 다음부터 거의 안 준다. 꺾이는 곳은 3이다.
  3. 그런데 3개 주머니를 열어 보면 네모와 L자가 한 주머니에 있다. 둘은 갈래 수가 같고 모양 비율만 조금(1과 1.5) 다르다. 실루엣 점수("내 주머니 친구와는 가깝고 옆 주머니와는 먼가", −1~1)는 4개(0.945)가 3개(0.936)보다 조금 높다.

방법마다 답이 다를 수 있다. 주머니 수는 숫자 하나로 정해지지 않고, 주머니를 열어 보고 "이 묶음으로 무엇을 할 것인가"와 함께 정한다.

이 칸의 한계 → 엘보도 실루엣도 결국 k를 하나씩 정해 놓고 돌려 본다. 주머니 수를 미리 정하지 않고, 가까운 것부터 짝지어 큰 그림(족보)을 먼저 볼 수는 없을까? 다음 칸.

수식으로 보기 — 실루엣 점수

데이터 i에 대해 a(i) = 같은 묶음 안 다른 데이터까지 평균 거리, b(i) = 가장 가까운 다른 묶음의 데이터까지 평균 거리. s(i) = (b(i) − a(i)) / max(a(i), b(i)). 모두 평균한 값이 실루엣 점수다[4]. 1에 가까우면 잘 나뉜 것, 0 근처면 경계에 걸친 것이다.

일상으로 치면

가족 족보를 아래에서부터 그린다. 가장 닮은 형제끼리 먼저 묶고, 그 형제들을 사촌과 묶고, 다시 육촌과 묶는다. 다 그린 다음 "몇 갈래로 볼까"는 족보의 어느 높이에서 가위로 자르느냐로 정한다.

모델에서는

처음에는 그림 하나가 한 묶음이다. 가장 가까운 두 묶음을 합치기를 하나만 남을 때까지 되풀이하면 나무(덴드로그램)가 생긴다. "묶음 사이 거리"를 가장 가까운 쌍으로 재면 최단 연결, 평균으로 재면 평균 연결, 가장 먼 쌍으로 재면 최장 연결이다[5][6]. 이것이 계층 군집이다.

초보자를 위한 풀이 — 족보로 본 연구실 식구

  1. 얼굴 그림은 32×32 칸 × 색 3개 = 숫자 3,072개다. 두 그림의 거리는 이 숫자들의 차이로 잰다.
  2. 평균 연결로 족보를 그리고 4묶음으로 자르면, 조수 그림 6장이 정확히 한 묶음에 모인다. 박사도 남은 5장이 한 묶음이다.
  3. 초파리와 주판봇도 거의 갈라졌다. 다만 한 장이 상대 묶음에 섞여 묶음 크기가 7장 / 5장이 됐다. 배경이 넓은 그림끼리는 픽셀 숫자로 닮아 보이기 때문이다. 그래서 맞는 비율은 95.8%(24장 중 23장)다.
  4. 5묶음으로 더 자르면 섞인 한 장이 풀리는 게 아니라, 그래프 판을 든 박사 그림 1장이 먼저 혼자 한 묶음으로 떨어져 나간다. 소품 하나 때문에 다른 그림과 멀어진 외톨이다. 외톨이 그림 3장이 모두 떨어져 나가는 7묶음에서야 섞인 한 장도 풀려 100%가 된다.

족보의 장점은 묶음 수를 미리 정하지 않아도 된다는 것이다. 단점은 외톨이 하나가 묶음 하나를 통째로 써 버릴 수 있고, 데이터가 많아지면 모든 쌍의 거리를 재야 해서 느리다는 것이다.

이 칸의 한계 → 지금까지 얼굴의 거리는 픽셀 숫자 3,072개를 그대로 비교했다. 배경이 넓고 옷이 어두우면 다른 사람끼리도 가까워진다. 얼굴의 "중요한 차이"만 남긴 짧은 숫자로 바꿀 수는 없을까? 1-3편 "얼굴을 지도 위 점으로".

코드 1 · 무엇을 잴지 고르고 주머니 수 고르기 — 표준화, 모양 비율, 엘보 방법
# 코드 1 · 무엇을 잴지 고르고 주머니 수 고르기 — 표준화, 모양 비율, 엘보 방법 (테트리스 블록 네 종류)
import numpy as np
rng = np.random.default_rng(0)

SHAPES = [[(0,0),(1,0),(2,0),(3,0)],   # 0 막대(I)
          [(0,0),(1,0),(0,1),(1,1)],   # 1 네모(O)
          [(0,0),(1,0),(2,0),(1,1)],   # 2 T자
          [(0,0),(0,1),(0,2),(1,2)]]   # 3 L자
def rotate(cells, t):
    c = np.array(cells)
    for _ in range(t): c = np.c_[-c[:, 1], c[:, 0]]
    return c - c.min(0)
def branches(c):                       # 한 칸에 붙은 이웃 칸의 가장 많은 수 (T자 3, 나머지 2)
    return max(sum(abs(a - x) + abs(b - y) == 1 for a, b in c) for x, y in c)

n = 300
kind = rng.integers(0, 4, n); vis = np.zeros((n, 2)); br = np.zeros(n)
for i in range(n):
    c = rotate(SHAPES[kind[i]], rng.integers(0, 4)); s = 9 + 6 * rng.random()   # 여러 회사 세트: 칸 9~15mm
    vis[i] = (c.max(0) + 1) * s + 0.5 * rng.standard_normal(2); br[i] = branches(c)
lo, sh = vis.max(1), vis.min(1)        # 긴 변·짧은 변: 돌려도 같은 값
z = lambda X: (X - X.mean(0)) / X.std(0)

def kmeans(X, k, restarts=5, iters=20):
    best = None
    for _ in range(restarts):
        C = [X[rng.integers(len(X))]]
        while len(C) < k:                                       # k-평균++ 시작
            D = np.min(((X[:, None] - np.array(C)[None]) ** 2).sum(-1), 1)
            C.append(X[rng.choice(len(X), p=D / D.sum())])
        C = np.array(C)
        for _ in range(iters):
            A = ((X[:, None] - C[None]) ** 2).sum(-1).argmin(1)
            C = np.array([X[A == j].mean(0) if (A == j).any() else C[j] for j in range(k)])
        inertia = ((X - C[A]) ** 2).sum()
        if best is None or inertia < best[0]: best = (inertia, A)
    return best

def purity(A, y): return sum(np.bincount(y[A == g]).max() for g in np.unique(A)) / len(y)

print("① 재는 법에 따라 달라지는 묶음 (k = 4, 종류와 일치)")
for name, X in [("보이는 가로·세로 (mm)", vis), ("긴 변·짧은 변 (mm)", np.c_[lo, sh]),
                ("+ 갈래 수 (mm 그대로)", np.c_[lo, sh, br]), ("세 특징을 표준화", z(np.c_[lo, sh, br])),
                ("모양 비율 + 갈래 수 (표준화)", z(np.c_[lo / sh, br]))]:
    print(f"  {name:22s} → {purity(kmeans(X, 4)[1], kind):.3f}")

print("② 엘보 방법: 주머니 수 k에 따른 묶음 안 거리 제곱합 (모양 비율 + 갈래 수, 표준화)")
Z = z(np.c_[lo / sh, br])
prev = None
for k in range(1, 9):
    inertia, A = kmeans(Z, k)
    drop = "" if prev is None else f"  (줄어든 양 {prev - inertia:6.1f})"
    print(f"  k = {k}: {inertia:6.1f}{drop}   종류와 일치 {purity(A, kind):.3f}")
    prev = inertia

① 재는 법에 따라 달라지는 묶음 (k = 4, 종류와 일치)
  보이는 가로·세로 (mm)         → 0.577
  긴 변·짧은 변 (mm)          → 0.627
  + 갈래 수 (mm 그대로)        → 0.627
  세 특징을 표준화              → 0.823
  모양 비율 + 갈래 수 (표준화)     → 1.000
② 엘보 방법: 주머니 수 k에 따른 묶음 안 거리 제곱합 (모양 비율 + 갈래 수, 표준화)
  k = 1:  600.0   종류와 일치 0.303
  k = 2:  282.0  (줄어든 양  318.0)   종류와 일치 0.533
  k = 3:    8.7  (줄어든 양  273.3)   종류와 일치 0.773
  k = 4:    1.9  (줄어든 양    6.8)   종류와 일치 1.000
  k = 5:    0.8  (줄어든 양    1.1)   종류와 일치 1.000
  k = 6:    0.5  (줄어든 양    0.3)   종류와 일치 1.000
  k = 7:    0.4  (줄어든 양    0.1)   종류와 일치 1.000
  k = 8:    0.3  (줄어든 양    0.1)   종류와 일치 1.000

코드 2 · 가까운 것부터 짝짓기 — 연결 방식 네 가지 대 k-평균 (손글씨 숫자 300장)
# 코드 2 · 가까운 것부터 짝짓기 — 계층 군집 대 k-평균 (손글씨 숫자 300장)
import numpy as np
from sklearn.datasets import load_digits
from scipy.cluster.hierarchy import linkage, fcluster
from sklearn.cluster import KMeans
X, y = load_digits(return_X_y=True)                 # y는 채점할 때만 쓴다
rng = np.random.default_rng(0)
idx = rng.choice(len(X), 300, replace=False); X, y = X[idx], y[idx]

def purity(A, y): return sum(np.bincount(y[A == g]).max() for g in np.unique(A)) / len(y)

print("숫자 300장을 10묶음으로 — 묶음이 실제 숫자와 맞는 정도")
for method in ["single", "average", "complete", "ward"]:
    Z = linkage(X, method=method)                   # 가장 가까운 두 묶음을 합치기를 되풀이
    A = fcluster(Z, t=10, criterion="maxclust")     # 나무를 10묶음이 되게 자르기
    sizes = sorted(np.bincount(A)[1:], reverse=True)
    print(f"  계층 군집 · {method:8s} → {purity(A, y):.3f}  (가장 큰 묶음 {sizes[0]}장, 가장 작은 묶음 {sizes[-1]}장)")
km = KMeans(n_clusters=10, n_init=10, random_state=0).fit(X)
print(f"  k-평균 (10번 다시 시작)  → {purity(km.labels_, y):.3f}")

숫자 300장을 10묶음으로 — 묶음이 실제 숫자와 맞는 정도
  계층 군집 · single   → 0.163  (가장 큰 묶음 286장, 가장 작은 묶음 1장)
  계층 군집 · average  → 0.767  (가장 큰 묶음 57장, 가장 작은 묶음 3장)
  계층 군집 · complete → 0.717  (가장 큰 묶음 57장, 가장 작은 묶음 17장)
  계층 군집 · ward     → 0.810  (가장 큰 묶음 47장, 가장 작은 묶음 20장)
  k-평균 (10번 다시 시작)  → 0.793
