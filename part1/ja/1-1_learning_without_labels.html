1教師あり

教師あり学習 — ラベルを見て学ぶ

モデル：新しいブロック → 最も似たラベル付きブロックの種類日常：先生が「これは棒、これはT字」と教える

日常でたとえると

先生がブロックをいくつか手に取り、「細長いこれは棒、丸くまとまったこれは四角、飛び出しているこれはT字」と教えてくれます。初めて見るブロックが来たら、教わったブロックの中で最も似ているものを思い出して名前を言います。

モデルでは

ブロックごとに長い辺と短い辺をmmで測ります。ブロックが寝ていても立っていても同じ値が出るように、「長い方」と「短い方」で測ります。ラベルの付いたブロックの中から、数値が最も近いブロックの名前に従います（最近傍法）[6]。正解（ラベル）を見て学ぶので教師あり学習です。

やってみよう — ラベルはいくつ付ければよいか

ラベル数4

動きで見る — 整理ロボットが新しいブロックを袋に入れる（試験ブロック200個）

初心者向けの解説 — 教師あり学習の3段階

  1. 数値に変える — ブロックごとに長い辺と短い辺を測ります。コンピュータは「細長い」を知らず、数字だけを知っています。色も見ません（白黒カメラ）。
  2. ラベルを付ける — 人がいくつかのブロックに「棒」「四角」「T字」と書き込みます。これが正解です。
  3. 新しいブロックを当てる — ラベル付きブロックの中で数値が最も近いものに従います。上の図の背景色がその結果です。ラベルを1つももらえなかった種類は、永遠に当てられません。

試験は別に。正確さは学習に使わなかった試験ブロック200個で測ります。すでに見たブロックで採点すると実力が膨らんで見えてしまいます。この原則はシリーズの最後まで続きます。

このマスの限界 → ラベルが多いほどよく当たりますが、ラベルは人が一つひとつ付けなければなりません。助手の写真1万枚にラベルを付ける人はいません。ラベルなしで整理することはできないでしょうか？ 次のマスへ。

2教師なし

教師なし学習 — 似たもの同士をまとめる

モデル：近い重心にまとめ、重心を動かすことを繰り返す（k-平均）日常：ブロックの山を袋に分けて入れる

日常でたとえると

ブロックの山を伏せて置き、いくつかの袋に分けて入れます。誰も名前を教えてくれなくても、「細長いもの同士」「丸っこいもの同士」を集めることはできます。ただし何を基準に集めるかは、整理する人が決めます。見えているそのままの「横に長いもの同士」で集めると、同じ棒でも寝ているものと立っているものが分かれてしまいます。

モデルでは

袋の数 k を決め、袋ごとに「重心」を1つ置きます。ブロックを最も近い重心の袋に入れ、袋の中のブロックの平均で重心を動かします。これを繰り返すのがk-平均です[1][2]。ラベルを使わないので教師なし学習です。

やってみよう — 何でまとめるか

基準
袋の数 k

動きで見る — 袋の中を開けてみると

初心者向けの解説 — 袋の整理の4段階

  1. 袋の数 k を決めます。（いくつに分けるかは人が決めます）
  2. 袋ごとに重心の位置を1つ選びます。互いに遠く離れたブロックを選ぶと、より良くなります（k-平均++）[3]。
  3. すべてのブロックを最も近い重心の袋に入れます。
  4. 袋の中のブロックの平均へ重心を動かし、3に戻ります。もう変わらなくなったら終わりです。

講義ノートでは、レゴの山を伏せて置き、色が似たもの・細長いもの同士で整理するたとえを使っています[8]。ここでは同じ考え方をテトリスブロックで試します。上の実験で長い辺・短い辺で3グループに分けると、種類と100%一致します。見えている横・縦で3グループに分けると69%に下がります。寝ている棒と立っている棒、寝ているT字と立っているT字が、別のグループになるからです。袋を5つに増やせば種類は分かれますが、そうすると棒という1種類が2つの袋に分かれてしまいます。データは同じでも、測り方を変えただけです。

このマスの限界 → グループには名前がありません。「1番の袋」が棒なのかT字なのかは、やはり誰かが見て確かめなければなりません。さらに、何で測るか、何が「うまく」まとまったのかを採点する正解もありません（色の正解表は私たちだけが見ます）。データが自分で採点表になることはできないでしょうか？ 次のマスへ。

数式で見る — k-平均が減らしている値

ブロック xᵢ、袋の重心 μ₁…μₖ、ブロックが入った袋 c(i) について、k-平均は J = Σᵢ ‖xᵢ − μc(i)‖² を減らします。3段階（近い袋に入れる）も4段階（平均へ動かす）も J を増やさないので、繰り返すと止まります。ただし出発点によっては別の場所で止まることがあるため（局所最小値）、出発の重心をうまく選ぶ k-平均++を使います[3]。

見えたままで測ったら、寝ている棒と立っている棒がバラバラになったよ。まとめる前に、何を測るかを先に決めないと。

3自己教師あり

自己教師あり学習 — 隠して、自分で当てる

モデル：隠された部分 = 見えている部分が最も似ている絵の、その部分日常：穴埋めパズル

日常でたとえると

顔写真の目・鼻・口を紙で隠して「隠された所はどんな形だろう？」と当てます。紙をはがせばすぐ正解が出ます。正解を教えてくれる先生は要りません。ブロックにたとえると、完成したテトリスの画面の何行かを隠して「ここにはどんなブロックがあったか？」を当て、はがして確かめるようなものです。

モデルでは

データの一部を自分で隠し、残りで隠された部分を当てさせます。正解は隠された部分そのものなので、人のラベルは0個です。これが自己教師あり学習です[4]。このマスのおもちゃは「見えている部分が最も似ている別の絵」から、隠された場所を持ってきます。

やってみよう — キャラクターの顔24枚、真ん中を隠して埋める

キャラクターごとに見られる絵の数5
1 / 24

動きで見る — パズルのピースが穴へ飛んでいく

初心者向けの解説 — 正解表なしで採点する方法

  1. 顔の絵を1つ選び、真ん中（目・鼻・口の近く）を自分で隠します。
  2. 残りの絵の中から、見えている部分が最も似ている絵を探します。
  3. その絵の真ん中を切り取り、穴にはめます。
  4. 原本と比べて誤差を測ります。正解は原本がすでに持っています。

見られる絵が増えるほど誤差が減りました（平均色で埋めると0.223、キャラクターごとに5枚見ると0.171）。もっと面白いことは別にあります。穴を埋めるために探した「いちばん似ている絵」が、24枚中23枚で同じキャラクターでした。誰も「これは助手」と教えていないのに、です。

教師なしか、自己教師ありか？講義で出た質問です。ラベルがないという点では教師なしと同じです。しかし「隠された部分を当てよ」という明確な採点基準があるので、自己教師あり学習と呼ぶ方が正確です。第2部では、この採点基準が「撮影された写真」になります。

このマスの限界 → このおもちゃは正面の絵同士しか比べません。横顔が入ってくると「見えている部分が似ている絵」を見つけられません。また、パズルをうまく解くことと「誰なのか見分けること」は同じ仕事ではありません。1-2の回からは、この2つをつなげていきます。

チャットボットの言語モデルもこのように学びます。文の中で単語を隠して当てたり（BERT）[7]、次の単語を当てたりします。正解は元の文がすでに持っているので、インターネット上の文章すべてがラベルのない教材になります。画像モデルも、絵のかけらのほとんどを隠して復元しながら学びます（MAE）[4]。

たとえの限界：実際のモデルは似た絵をそのまま写すのではなく、膨大な絵から学んだ規則で新しく描きます。このマスのおもちゃは「写してくる」方式なので、初めて見る顔は埋められません。

コード1 · テトリスブロックの整理 — 教師あり、教師なし（k-平均）、ラベル予算の対決
# 코드 1 · 테트리스 블록 정리하기 — 지도 학습, 비지도 학습(k-평균), 그리고 이름표 예산 대결
import numpy as np
rng = np.random.default_rng(0)

SHAPES = {0: [(0,0),(1,0),(2,0),(3,0)],      # 막대(I)
          1: [(0,0),(1,0),(0,1),(1,1)],      # 네모(O)
          2: [(0,0),(1,0),(2,0),(1,1)]}      # T자
def rotate(cells, t):                       # 90°씩 t번 돌리기
    c = np.array(cells)
    for _ in range(t): c = np.c_[-c[:, 1], c[:, 0]]
    return c - c.min(0)

def make(n):
    """막대·네모·T자 블록 n개. 아무 방향으로 놓였고, 칸 크기 약 12mm, 재는 오차 0.5mm.
    AI는 흑백 카메라로 모양만 잰다: 보이는 가로·세로(vis), 긴 변·짧은 변(shape). 색 = 종류(사람만 보는 정답)"""
    kind = rng.integers(0, 3, n); vis = np.zeros((n, 2))
    for i in range(n):
        c = rotate(SHAPES[kind[i]], rng.integers(0, 4)); s = 11.2 + 1.6 * rng.random()
        vis[i] = (c.max(0) + 1) * s + 0.5 * rng.standard_normal(2)
    shape = np.c_[vis.max(1), vis.min(1)]           # 돌려도 같은 값
    orient = (vis[:, 0] < vis[:, 1]).astype(int)    # 0 = 누움, 1 = 섬
    return kind, shape / 10, vis / 10, orient

def nn_predict(Xl, yl, X):                           # 가장 닮은 이름표 블록을 따른다
    d = ((X[:, None, :] - Xl[None, :, :]) ** 2).sum(-1)
    return yl[d.argmin(1)]

def kmeans(X, k, iters=12):                          # k-평균 (k-평균++ 시작)
    C = [X[rng.integers(len(X))]]
    while len(C) < k:
        D = np.min(((X[:, None] - np.array(C)[None]) ** 2).sum(-1), 1)
        C.append(X[rng.choice(len(X), p=D / D.sum())])
    C = np.array(C)
    for _ in range(iters):
        A = ((X[:, None] - C[None]) ** 2).sum(-1).argmin(1)
        C = np.array([X[A == j].mean(0) if (A == j).any() else C[j] for j in range(k)])
    return A, C

def purity(A, y):                                    # 묶음마다 가장 많은 값의 비율
    return sum(np.bincount(y[A == g]).max() for g in np.unique(A)) / len(y)

kind, shape, vis, orient = make(300); tk, ts, _, _ = make(200)

print("① 지도 학습: 이름표 수에 따른 시험 정확도 (20번 평균)")
for n in [2, 4, 6, 10, 40]:
    accs = []
    for _ in range(20):
        idx = rng.choice(300, n, replace=False)
        accs.append((nn_predict(shape[idx], kind[idx], ts) == tk).mean())
    print(f"  이름표 {n:2d}개 → {np.mean(accs):.3f}")

print("② 비지도 학습: 무엇으로 재느냐에 따라")
for name, X, k in [("긴 변·짧은 변으로 3묶음", shape, 3), ("보이는 가로·세로로 3묶음", vis, 3), ("보이는 가로·세로로 5묶음", vis, 5)]:
    A, _ = kmeans(X, k)
    print(f"  {name}: 종류와 일치 {purity(A, kind):.3f}, 방향(누움·섬)과 일치 {purity(A, orient):.3f}")

print("대결: 이름표 예산 4개 (50번 평균)")
f_acc, r_acc = [], []
for _ in range(50):
    kind, shape, vis, orient = make(300); tk, ts, _, _ = make(200)
    idx = rng.choice(300, 4, replace=False)                      # 주판봇: 무작위 4개에 이름표
    r_acc.append((nn_predict(shape[idx], kind[idx], ts) == tk).mean())
    A, C = kmeans(shape, 3)                                      # 초파리: 먼저 묶고
    names = [kind[np.where(A == j)[0][((shape[A == j] - C[j]) ** 2).sum(1).argmin()]] for j in range(3)]
    pred = np.array(names)[((ts[:, None] - C[None]) ** 2).sum(-1).argmin(1)]   # 묶음마다 1개만 이름표
    f_acc.append((pred == tk).mean())
print(f"  초파리(묶고 이름표 3개) {np.mean(f_acc):.3f} · 주판봇(이름표 4개) {np.mean(r_acc):.3f}")

コード2 · 隠して当てる — 手書き数字の真ん中を、他の絵だけを見て埋める
# 코드 2 · 가리고 맞히기 — 이름표 없이, 다른 그림만 보고 가린 부분 채우기 (자기 지도 학습의 씨앗)
import numpy as np
from sklearn.datasets import load_digits          # Colab에 기본으로 있는 8×8 손글씨 숫자 1,797장
X, y = load_digits(return_X_y=True)                # y(숫자 이름표)는 채점할 때만 쓴다
img = X.reshape(-1, 8, 8) / 16.0
mask = np.zeros((8, 8), bool); mask[2:6, 2:6] = True   # 가운데 4×4를 가린다

rng = np.random.default_rng(0)
test = rng.choice(len(X), 300, replace=False)
for n_train in [10, 50, 200, 1000]:
    rest = np.setdiff1d(np.arange(len(X)), test)
    train = rng.choice(rest, n_train, replace=False)
    vis = img[:, ~mask]                            # 보이는 칸만
    err_fill, err_gray, same = [], [], []
    for t in test:
        d = ((vis[train] - vis[t]) ** 2).sum(1)    # 보이는 칸이 가장 닮은 그림을 찾고
        b = train[d.argmin()]
        err_fill.append(np.abs(img[b][mask] - img[t][mask]).mean())        # 그 그림의 가운데로 채운다
        err_gray.append(np.abs(vis[t].mean() - img[t][mask]).mean())       # 기준선: 평균 밝기로 채우기
        same.append(y[b] == y[t])                  # 이름표 없이 찾은 그림이 같은 숫자였나?
    print(f"학습 그림 {n_train:4d}장 → 채운 오차 {np.mean(err_fill):.3f} (평균 밝기로 채우면 {np.mean(err_gray):.3f}) · 같은 숫자를 찾은 비율 {np.mean(same):.3f}")

학습 그림   50장 → 채운 오차 0.289 (평균 밝기로 채우면 0.422) · 같은 숫자를 찾은 비율 0.650
학습 그림  200장 → 채운 오차 0.236 (평균 밝기로 채우면 0.422) · 같은 숫자를 찾은 비율 0.803
학습 그림 1000장 → 채운 오차 0.190 (평균 밝기로 채우면 0.422) · 같은 숫자를 찾은 비율 0.900
