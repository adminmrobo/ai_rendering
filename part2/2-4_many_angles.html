왜 이 주제인가

13D 스캔의 가장 오래된 방법

여러 사진의 실루엣을 겹쳐 모양을 얻는 방법은 1970년대부터 쓰였고, 실루엣만으로 얻을 수 있는 가장 좋은 모양을 "시각 껍질"이라 부른다[1]. 지금도 사람 몸 스캔, 스튜디오 촬영의 첫 단계로 쓰인다[4].

2무엇을 알 수 없는지 알려 준다

시각 껍질은 "실루엣으로는 여기까지"라는 천장을 정확히 보여 준다. 컵 속처럼 오목한 곳은 실루엣을 아무리 모아도 드러나지 않는다[1].

3NeRF로 가는 다리

실루엣(덮였나 아닌가) 대신 색이 사진들과 맞는지를 보면 오목한 곳도 깎을 수 있다[2]. 이 생각을 신경망으로 밀고 간 것이 NeRF다[3]. 공간의 점마다 "얼마나 차 있고 무슨 색인가"를 여러 사진에 맞춰 배운다.

수식으로 보기 — 실루엣 기둥

카메라 c의 실루엣 Sᶜ(사진 위 0/1)와 투영 πᶜ(점 → 사진 자리)로, 칸 가운데 점 p를 Sᶜ(πᶜ(p)) = 0이면 지운다. 사진 한 장이 남기는 것은 Kᶜ = {p : Sᶜ(πᶜ(p)) = 1}, 카메라에서 실루엣을 통과하는 광선들이 만드는 뿔(기둥)이다. 여러 장이면 H = ∩ᶜ Kᶜ. 진짜 물체 X는 언제나 X ⊆ H다[1].

수식으로 보기 — 시각 껍질과 천장

무한히 많은 방향에서 본 실루엣으로 얻는 껍질을 Laurentini는 시각 껍질 VH(X)라 정의했다[1]. 실루엣이 같은 물체들은 구별되지 않으므로, 실루엣으로 얻을 수 있는 최선은 VH(X)다. 둘레(높이 15°)의 유한한 n장이면 X ⊆ VH(X) ⊆ Hₙ이고, n이 늘면 Hₙ은 VH(X)로 줄어든다. 머그컵의 VH는 "속을 채운 컵(+ 손잡이)"이라 IoU(X, VH) = 2,504 / 7,840 ≈ 31.9%가 천장이다.

3두 구멍

뚫린 구멍과 오목한 구멍 — 천장의 정체

모델: 실루엣에 드러나는 구멍만 깎인다일상: 도넛 구멍은 보이고, 그릇 속은 그림자에 안 보인다

일상으로 치면

도넛을 세워 손전등을 비추면 그림자 가운데 구멍이 뚫려 보인다. 그릇은 어느 쪽에서 비춰도 그림자가 꽉 찬 모양이다. 그릇 속이 비었다는 건 그림자로는 알 수 없다.

모델에서는

손잡이 구멍은 뚫린 구멍이다. 맞는 방향(앞)에서 보면 빛이 통해 실루엣에도 구멍이 생기고, 깎인다. 컵 속은 오목한 구멍이다. 컵 속을 지나는 광선은 어느 방향이든 먼저 벽이나 테두리를 지나므로, 실루엣은 늘 "속이 찬 컵" 모양이다. 그래서 컵 속 칸은 지울 근거가 없다[1]. 컵 속을 파려면 실루엣 말고 다른 정보(색, 깊이)가 필요하다[2][3].

행동으로 보기 — 고리와 그릇에 광선 쏘기

초보자를 위한 풀이 — 무엇이 남나

  1. 손잡이 구멍: 앞 한 장으로도 100%. 앞에서 보면 손잡이 구멍으로 배경이 보인다. 옆(90°) 한 장으로는 손잡이가 몸통에 겹쳐 0%. 뚫린 구멍도 맞는 방향에서 봐야 한다.
  2. 컵 속: 무엇을 해도 0%. 둘레 8장도, 위에서 내려다본 사진을 더해도 컵 속 5,336칸은 하나도 깎이지 않는다. 위에서 본 실루엣도 테두리 동그라미 하나다.
  3. 카메라를 높여도 안 된다. 둘레 8장을 높이 0°에서 찍으면 27.2%, 15° 25.4%, 30° 22.7%, 60° 17.9%, 89°(바로 위) 9.7%. 높일수록 컵 밑 쐐기가 커지고 사진들이 서로 비슷해져 오히려 나빠진다. 컵 속은 어느 높이에서도 0%다.

이 칸의 한계 → 실루엣은 "덮였나 아닌가"만 담는다. 위에서 본 사진의 밝기나 카메라까지의 거리(깊이)를 쓰면 컵 속 바닥이 테두리보다 멀다는 것을 알 수 있다. 다음 편 2-5 「머그컵을 3D로」에서 실루엣과 깊이를 합쳐 손잡이와 컵 속까지 되찾는다.

수식으로 보기 — 공간 깎기와 NeRF

공간 깎기[2]는 칸이 실루엣 안에 있는지 대신, 그 칸이 보이는 사진들에서 같은 색으로 찍히는지(사진 일관성)를 본다. 맞지 않으면 지운다. 그러면 위에서 보이는 컵 속 바닥 색과 테두리 색이 다르다는 것으로 오목한 곳도 판다. NeRF[3]는 칸을 0/1로 지우는 대신 점마다 밀도 σ와 색 c를 신경망으로 두고, 광선 위 점들을 Σ Tᵢ (1 − e−σᵢδᵢ) cᵢ로 섞은 색이 모든 사진과 맞도록 기울기로 배운다(2-3의 미끄럼 타기). 실루엣 깎기는 "색 없이, 0/1로만" 하는 가장 단순한 경우다.

코드 1 · 실루엣 깎기 — 사진 수와 배치에 따른 겹친 비율, 천장
# 코드 1 · 실루엣 깎기 — 사진 수와 배치(둘레에 고르게 vs 앞쪽에 몰아서)에 따른 겹친 비율
import numpy as np
def cyl(p, r, h):
    dx = np.hypot(p[..., 0], p[..., 2]) - r; dy = np.abs(p[..., 1]) - h/2
    return np.minimum(np.maximum(dx, dy), 0) + np.hypot(np.maximum(dx, 0), np.maximum(dy, 0))
def mug(p, handle=True):
    """위가 열린 머그컵(반지름 1, 높이 1.6, 벽 0.14) + 오른쪽(+x) 손잡이 고리"""
    body = np.maximum(cyl(p, 1, 1.6), -cyl(p - [0, .14, 0], .86, 1.6))
    q = np.hypot(p[..., 0] - 1.05, p[..., 1]) - .42; return np.minimum(body, np.hypot(q, p[..., 2]) - .09) if handle else body
def camera(az, el, dist=4.5, f=2.2):
    a, e = np.radians(az), np.radians(el); pos = dist*np.array([np.sin(a)*np.cos(e), np.sin(e), np.cos(a)*np.cos(e)])
    fw = -pos/np.linalg.norm(pos); rt = np.array([fw[2], 0, -fw[0]]); rt /= np.linalg.norm(rt); return pos, fw, rt, np.cross(rt, fw), f
def silhouette(cam, res=64):
    pos, fw, rt, up, f = cam
    u, v = np.meshgrid((np.arange(res) + .5)/res*2 - 1, 1 - (np.arange(res) + .5)/res*2)
    d = fw*f + rt*u[..., None] + up*v[..., None]; d /= np.linalg.norm(d, axis=-1, keepdims=True)
    t = np.zeros(u.shape); hit = np.zeros(u.shape, bool)
    for _ in range(96):
        s = mug(pos + d*t[..., None]); hit |= s < 1e-3; t = np.where(hit, t, t + .9*s)
    return hit
g, B = 40, 1.7; c = -B + (np.arange(g) + .5)*2*B/g
P = np.stack(np.meshgrid(c, c, c, indexing='ij'), -1).reshape(-1, 3)        # 40×40×40 칸의 가운데 점
true = mug(P) < 0; inside = cyl(P, 1, 1.6) < 0                              # 진짜 컵, 속을 채운 컵
def carve(cams, res=64):
    keep = np.ones(len(P), bool)
    for cam in cams:
        pos, fw, rt, up, f = cam; q = P - pos; z = q @ fw
        u = f*(q @ rt)/z; v = f*(q @ up)/z                                   # 칸을 사진 위로 옮기기 (투영)
        x = np.floor((u + 1)/2*res).astype(int); y = np.floor((1 - v)/2*res).astype(int)
        ok = (x >= 0) & (y >= 0) & (x < res) & (y < res); S = silhouette(cam, res)
        keep &= ok & S[np.clip(y, 0, res - 1), np.clip(x, 0, res - 1)]       # 실루엣 밖이면 지운다
    return keep
iou = lambda a, b: (a & b).sum()/(a | b).sum()
print(f"진짜 컵 {true.sum()}칸 · 천장(속을 채운 컵과의 겹친 비율) {100*iou(true, true | inside):.1f}%")
print(" 사진 수 | 둘레에 고르게 | 앞쪽 60° 안에")
for n in (1, 2, 3, 4, 6, 8, 12, 16):
    ring = [camera(360*k/n, 15) for k in range(n)]
    front = [camera(0, 15)] if n == 1 else [camera(-30 + 60*k/(n - 1), 15) for k in range(n)]
    print(f"   {n:2d}   |    {100*iou(true, carve(ring)):5.1f}%    |   {100*iou(true, carve(front)):5.1f}%")
