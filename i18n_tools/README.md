| 단계 | 명령 | 하는 일 |
|---|---|---|
| extract | `python3 extract.py <한국어 html> <units.json>` | 화면 글(본문 인라인 묶음, 속성 alt·aria-label·title, 스크립트 문자열, kg-raw 이름·정의, refs 쓰인 곳, page-meta)을 단위로. `<pre>`(Colab 코드·결과)와 JSON-LD는 뺀다. 짧은 스크립트 조각엔 앞뒤 40자 hint |
| pending | `python3 pack.py <L> <units.json…>` | 번역 메모리(tm/L.json)에 없는 단위만 약 1만 1천 자 묶음으로, 언어별 glossary를 붙여 |

| merge | `merge.build(...)` | 끼워 넣기, 지식 색인 이름·정의 현지화(label.L), 영어판은 영어 보조 이름 숨김, `<html lang>`, 번역 안 된 편 링크는 한국어판으로, 언어 전환 줄(자동 전환·?lang=·#섹션 유지) |

## 전체판 (2026-11-02) — 18쪽 × 6개 언어

- 배치: `partN/{en,zh,ja,ru,uz,vi}/이름.html`, 한국어판 `partN/이름.html`에 언어 전환 줄. 다른 부(part)로 가는 링크도 같은 언어판으로 이어진다.
- 묶기: `pack2.py` — 이미 번역 메모리에 있는 원문은 빼고 2만 5천 자 묶음 13개/언어. 번역은 en·zh·ja haiku, ru·uz·vi sonnet.
- 합치기: `python3 mergeall.py <출력 폴더> en,zh,ja,ru,uz,vi`. 데이터 블록에 남는 짧은 한글(출처 위치, 저자 이름, 수준 등 30여 개)은 `extra.json` 사전으로. 같은 원문이 여러 문맥에 있으면 조각 번역 중 가장 많은 것을 쓴다.
- 손 보정: `accept.py L 묶음 id[,id] [고친 번역.json]`, 저자 이름은 `fixname2.py`.
- 화면 검사: `python3 vt2.py <사이트 폴더> L 1280|390` — 스크립트 오류, 가로 넘침, 화면에 남은 한글(코드 상자 제외), 버튼 40개 눌러 본 뒤.
