# 번역 공통 규칙 (AI 렌더링 연구실)
대상: 한국어 인터랙티브 교육 페이지(그래픽스·AI 입문). 독자는 대학생·교사·입문자. 문체는 부드럽고 친절하게.

## 출력
- 묶음의 모든 id를 빠짐없이 옮겨 `{"u0001":"번역", ...}` JSON 객체 하나만 쓴다. 설명·코드 블록·원문 반복 금지.
- JSON 문자열 규칙을 지킨다(큰따옴표는 \", 줄바꿈은 \n).

## 그대로 둘 것
- HTML 태그와 속성: 같은 태그를 같은 순서로, 속성값(class, href, style, data-*)은 바꾸지 않는다. 태그 안의 글만 옮긴다.
- 엔티티(&lt; &amp; &quot;), 수식 기호(∩ ∪ ‖ Σ ε σ ≈ → × ÷ − ±), 아래·위 첨자 문자, 출처 번호 [1].
- 숫자와 단위: 12.5%, 0.07, 64×64, 1,072칸 → 숫자는 그대로(천 단위 쉼표 포함). "칸·장·걸음" 같은 세는 말은 자연스럽게 옮긴다.
- 고유 이름: M-Robo, DLSS, NeRF, KinectFusion, Colab, numpy, PyTorch, 논문 제목·저자 이름, CC BY-NC 4.0.
- 기호 〔 〕, 「 」 안의 말은 옮기되 기호 모양은 언어 습관에 맞게 바꿔도 된다.

## 조각(hint가 있는 단위)
- hint는 자바스크립트 코드 속 앞뒤 모습이다. 조각은 `'…'+값+'…'`로 이어 붙는다. 이어 붙였을 때 자연스러운 문장이 되도록 조각만 옮긴다.
- 조각 앞뒤의 공백은 원문과 똑같이 둔다(중국어·일본어는 한자·가나 옆 공백을 빼도 된다).
- 조각이 조사·어미뿐이어도(예: "은 ", "장") 그 자리에 맞는 말을 넣는다. 필요 없으면 빈 문자열이 아니라 공백 하나 또는 알맞은 단위를 쓴다.

## 용어
- 묶음의 `glossary`에 있는 번역을 그대로 쓴다.
- 처음 보는 전문 용어는 그 언어의 교과서 표현을 쓰고, 필요하면 괄호에 영어를 붙인다.

## 등장인물 말투
- 박사: 정중하고 차분하게. 조수(하루): 밝고 호기심 많게. 초파리 연구원: 의심 많고 무뚝뚝하게(반말 느낌). 주판봇(연구실 로봇 — en·uz·vi AbaBot, ja アバボット, zh 算盘宝, ru АбаБот): 장사꾼처럼 자신만만하게(반말 느낌).
- 저자 "안상선 ((주)M-Robo 대표)"는 glossary의 표기를 쓴다.

## 숫자 표기
- 한국어 "만"(10,000)이 있으면 숫자로 풀어 쓴다. 소수점은 원문처럼 점(.)을 쓴다.
